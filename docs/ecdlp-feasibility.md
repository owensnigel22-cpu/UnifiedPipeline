# Addressing ECDLP Literature: Feasibility and Recommendations

This note summarizes relevant classical elliptic-curve discrete logarithm
(ECDLP) research and identifies bounded experiments that fit this workspace.
It is background, not a claim that secp256k1 private keys can be recovered.

## Summation polynomials and index calculus

Semaev's summation polynomials encode when points with selected
x-coordinates can be signed so that their sum is the identity. For a
short-Weierstrass curve, the three-variable polynomial `S3` gives a relation
among three x-coordinates; higher summation polynomials express analogous
relations involving more points. These are algebraic tools for constructing
relations, not direct evaluations of an unknown private scalar.

Summation-polynomial methods have been studied for elliptic curves over
different finite fields, including prime fields. Their existence does not
make them an effective attack on every curve. Index-calculus approaches need
more than the polynomial relation: they need a factor base, a way to find
enough sufficiently smooth relations, and linear algebra to combine those
relations. The cost of those steps depends strongly on the field and curve
family. It is therefore too broad to say that summation polynomials only
apply to extension fields; the practical point is that no such method is
known to give a practical subexponential attack on secp256k1.

The phrase “squares of primes in a polynomial structure” does not describe a
known general method for solving the secp256k1 ECDLP. Integer factorization
and elliptic-curve discrete logarithms are different problems. A useful
algebraic relation must be derived from the curve group law and shown to
produce enough exploitable relations; a polynomial containing prime squares
does not by itself provide that.

## Generic attacks and practical limits

For a generic cyclic group of order `n`, Pollard rho has expected work on the
order of `sqrt(n)` group operations. Distinguished-point methods allow
independent workers to collaborate, reducing elapsed time approximately with
the number of workers in an idealized setting, but they do not remove the
underlying total-work requirement. Pollard kangaroo (lambda) is useful when
the discrete logarithm is known to lie in a bounded interval; it is not a
shortcut for an unrestricted 256-bit secp256k1 private key.

These generic methods are useful for small toy groups and carefully bounded
experiments. Parallelization does not make a group with more than `2^100`
elements practically attackable merely because many workers are available.
Claims about practical feasibility need to account for group-operation rate,
memory, communication, and total work, not only worker count.

## Bounded experiments suitable for this workspace

The existing secp256k1 module provides reference point operations and scalar
multiplication. They are variable-time and intended for education, not
production secret-key operations.

Useful, limited extensions would be:

1. **`S3` evaluator:** implement a finite-field evaluator for a selected
   curve, document its sign/root semantics, and test it against points
   generated by the curve's group law. This checks algebraic identities; it
   is not a private-key recovery method.
2. **Toy Pollard kangaroo:** implement a bounded-interval discrete-log demo
   over a small, explicitly defined group. Verify recovered scalars against
   known points and test interval boundaries. Do not present its runtime as a
   secp256k1 attack estimate.
3. **Further reading:** study summation-polynomial relation generation and
   the distinction between prime-field and extension-field ECDLP algorithms
   before drawing conclusions about a particular curve.

Neither experiment is currently implemented by this document. Any future
solver should have explicit limits, tests against known toy instances, and
clear warnings separating toy behavior from production-curve feasibility.

## References and terminology

- I. Semaev, “Summation Polynomials and the Discrete Logarithm Problem on
  Elliptic Curves,” *Cryptology ePrint Archive*, Report 2004/031.
- P. Gaudry, “Index calculus for abelian varieties and the elliptic curve
  discrete logarithm problem,” *Mathematics of Computation*, 72 (2003),
  921–935.
- J. M. Pollard, “Monte Carlo methods for index computation (mod p),”
  *Mathematics of Computation*, 32 (1978), 918–924.

Here, “ECDLP” means: given a point `Q = dG` in a specified subgroup, find
the scalar `d` modulo the subgroup order. It is not the same as factoring an
RSA modulus, finding a hash preimage, or recovering a signing nonce from
unrelated hash state.
